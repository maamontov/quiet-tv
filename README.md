# Quiet TV

Минимальный нативный лаунчер для **Android TV / Google TV с Android 8.0 и новее**. Одна горизонтальная полоса крупных приложений по центру экрана, мягкая подсветка в цвет выбранной карточки и центр уведомлений внизу.

Приложение написано на Java и стандартных Android Views. В нём нет сторонних библиотек, рекламы, телеметрии, сетевого доступа или опроса по таймеру. Проверено на Philips / TPV с Android 11; выбор входов и возможность смены главного экрана зависят от прошивки телевизора.

## Установить готовую версию

Скачайте `quiet-tv-0.4.0.apk` из [Releases](https://github.com/maamontov/quiet-tv/releases/latest). Это APK приложения, а не архив исходников.

Установите APK через доступный на телевизоре установщик или ADB. Сначала откройте Quiet TV как обычное приложение и проверьте работу пульта, настроек и входов. Затем выберите его главным экраном через настройки Android или меню Quiet TV.

### Установка через ADB

Нужны [Android SDK Platform Tools](https://developer.android.com/tools/releases/platform-tools) и разрешённая отладка на телевизоре. Подставьте адрес подключения, который показывает ваш ТВ; пример `192.0.2.10` ниже — условный адрес, не адрес устройства автора. На устройствах с сопряжением сначала выполните `adb pair` с адресом и кодом, показанными на телевизоре.

```sh
TV_SERIAL="192.0.2.10:5555"
adb connect "$TV_SERIAL"
adb -s "$TV_SERIAL" install --no-incremental -r quiet-tv-0.4.0.apk
adb -s "$TV_SERIAL" shell am start -n local.quiet.tv/.MainActivity
```

В Android должен появиться вариант главного экрана Quiet TV. Через ADB его можно выбрать так:

```sh
adb -s "$TV_SERIAL" shell cmd package set-home-activity --user 0 local.quiet.tv/.MainActivity
adb -s "$TV_SERIAL" shell input keyevent 3
```

На проверенном Philips штатный лаунчер имеет более высокий приоритет. Если назначение главного экрана не срабатывает, **после проверки Quiet TV** можно отключить только штатный пакет лаунчера для пользователя 0:

```sh
adb -s "$TV_SERIAL" shell pm disable-user --user 0 com.google.android.tvlauncher
adb -s "$TV_SERIAL" shell input keyevent 3
```

Эта команда предназначена для прошивок, где штатный пакет — именно `com.google.android.tvlauncher`. На других телевизорах он может отличаться. Не отключайте системные службы ТВ или LiveTV: они нужны, в том числе, для выбора HDMI.

Возврат штатного лаунчера на этом Philips:

```sh
adb -s "$TV_SERIAL" shell pm default-state --user 0 com.google.android.tvlauncher
adb -s "$TV_SERIAL" shell cmd package set-home-activity --user 0 com.google.android.tvlauncher/.MainActivity
adb -s "$TV_SERIAL" shell am start -n com.google.android.tvlauncher/.MainActivity
adb -s "$TV_SERIAL" shell cmd notification disallow_listener local.quiet.tv/.NotificationFeed 0
```

Есть и готовый скрипт возврата: `python3 tools/restore-philips-home.py --serial "$TV_SERIAL"`. Он ждёт сохранения настроек Android. Удаляйте Quiet TV после возврата работающего штатного главного экрана.

## Управление пультом

| Кнопка | Действие |
| --- | --- |
| Влево / вправо | Выбрать приложение |
| OK | Открыть приложение |
| Удерживать OK | Меню «Переместить / Скрыть» |
| Вверх из ряда | Входы и настройки |
| Вниз из ряда | Плашка уведомлений |
| OK на плашке | Список уведомлений |
| Вверх с плашки | Последнее выбранное приложение |
| Назад в списке | Закрыть список |
| Home | Закрыть меню и вернуться к началу ряда |

В режиме перемещения стрелки меняют место плитки, OK сохраняет, «Назад» отменяет. Скрытые приложения возвращаются через «Настройки → Вернуть скрытые приложения». Скрытие не удаляет приложение. Порядок и скрытие сохраняются локально.

## Уведомления

Плашка показывает последнее **активное сообщение** и счётчик. Нажатие открывает список: новые сообщения сверху, фокус сохраняется при обновлении. OK на сообщении с действием выполняет его исходный `PendingIntent`. Когда приложение удаляет уведомление, оно исчезает и из Quiet TV.

Нужен специальный доступ к уведомлениям. При отсутствии доступа плашка предлагает открыть соответствующие настройки Android. Альтернативная команда для прошивок, где это поддерживается:

```sh
adb -s "$TV_SERIAL" shell cmd notification allow_listener local.quiet.tv/.NotificationFeed 0
```

Центр использует один системно привязанный `NotificationListenerService`. Он обновляется по событиям Android, без постоянного опроса. История сообщений не записывается на диск и не передаётся в сеть. Постоянные статусы с флагом `ongoing` и сводки групп не показываются. Сами уведомления и службы Android при этом не отключаются. Доступность слушателя на конкретной модели определяется Android и политиками прошивки.

## Собрать самостоятельно

Нужны:

- Python 3.9 или новее.
- Полный JDK 25 с компилятором и `keytool` в `PATH`.
- Android SDK Platform **35** и Build Tools **35.0.0**.

SDK можно установить через Android Studio → SDK Manager или официальные [Command-line Tools](https://developer.android.com/tools). При первоначальной установке SDK примите его условия лицензии. Если `sdkmanager` доступен в `PATH`:

```sh
sdkmanager "platforms;android-35" "build-tools;35.0.0"
```

Сборка из корня проекта:

```sh
python3 build.py --sdk /absolute/path/to/android-sdk
python3 tests/run.py
```

Либо задайте `ANDROID_HOME` и запустите `python3 build.py`. На Windows вместо `python3` можно использовать `py -3`. Выходной файл — `build/quiet-tv.apk`. Для установки собственной сборки замените имя APK в командах выше этим путём.

Скрипт использует официальные `aapt2`, `javac`, `d8`, `zipalign` и `apksigner`, проверяет подпись APK и не загружает зависимости из Maven. После установки SDK сборка работает офлайн. Флаги `--java`, `--keytool`, `--output` позволяют изменить используемые программы и путь результата; подробности — `python3 build.py --help`.

### Подпись и обновления

При первой локальной сборке создаётся собственный ключ `.signing/local.p12`. Сохраняйте его для следующих обновлений; он исключён из Git. Это ключ для личной сборки, а не общий ключ проекта. APK из Releases подписан другим, закрытым ключом автора.

Android принимает обновление только с прежней подписью. Чтобы заменить APK из Releases своей сборкой или наоборот, обычно нужно удалить прежнюю установку, что удалит её настройки. На телевизоре сначала выберите другой рабочий главный экран.

### GitHub Actions

Workflow **Build APK** запускает тест навигации, собирает APK и сохраняет его в артефакт `quiet-tv-ci`. Его можно запустить вручную из вкладки Actions. Для CI создаётся временный ключ: такой APK подходит для проверки, но его подпись меняется между запусками. Для обычной установки и обновлений используйте APK из Releases или собственный сохранённый ключ.

## Устройство проекта

- `MainActivity.java` — главный экран, пульт и меню приложений.
- `AppCatalog.java` — обнаружение приложений и кеш баннеров.
- `TvStyle.java` — отрисовка и анимации.
- `NotificationFeed.java` — системный слушатель активных уведомлений.
- `NotificationsPanel.java` — плашка и список уведомлений.
- `tests/` — проверка границ и достижимости навигации в 512 формах сетки.

Баннеры скругляются при загрузке; мягкий ореол хранится одной общей текстурой и окрашивается в цвет баннера. Прокрутка сохраняет скорость при повторных нажатиях. В покое анимационного цикла нет. Реализация выбора входов использует существующее меню Philips и не заменяет LiveTV. Лаунчер не меняет декодирование видео, сеть или скорость самих видеоприложений.
